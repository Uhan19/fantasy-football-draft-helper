# Optional assistant connection

Download the Mac `tunnel-client` from [OpenAI tunnel settings](https://platform.openai.com/settings/organization/tunnels), unpack it if needed, and place the executable in this folder with the name `tunnel-client`.

Reopen **Start War Room.command**. The setup page will recognize it. You can also keep an existing installation in `/usr/local/bin`, `/opt/homebrew/bin`, or your PATH.

Only the small README belongs in Git. Downloaded binaries in this folder are ignored. The draft dashboard does not require the tunnel client.
