Private league? Add ESPN sign-in cookies

Public leagues can skip this. Private leagues need two values from your signed-in ESPN browser. They are stored only in this project’s local settings file.

Where do I find these in Chrome?
  1. Sign in at ESPN Fantasy.
  2. Choose View → Developer → Developer Tools. Select Application (it may be inside the » menu).
  3. Under Storage → Cookies, select the ESPN domain. Copy the values named espn_s2 and SWID into the matching fields above.

Keep these values private. War Room uses them to read your league; it never submits draft picks.

Connect your assistant

The dashboard works on its own. An assistant also needs OpenAI’s tunnel client, a tunnel ID, and a runtime API key.

  1. Open OpenAI tunnel settings and create or choose your tunnel. Download the Mac tunnel client there.
  2. Unpack the download and drag the tunnel-client executable into this project’s tools folder. Reopen the launcher to check it.
  3. Get a runtime key from OpenAI API keys in the same organization. Your account needs Tunnels Read + Use.

Already in your .env? War Room loads CONTROL_PLANE_API_KEY automatically. No Terminal paste or export command is needed.
